📌 نظرة سريعة على V3:
════════════════════════════════════════════════════════════════════════════════

V3 إعادة هندسة كاملة مع:
✅ شاشة ممتدة بدون sidebar
✅ سبورة سوداء تفاعلية (Blackboard)
✅ نوافذ عائمة (Dialogs)

✅ حفظ تلقائي للنتائج

🚀 التشغيل الفوري:
════════════════════════════════════════════════════════════════════════════════

pip install -r requirements.txt
streamlit run app_streamlit_v3.py


📱 الهيكل الرئيسي:
════════════════════════════════════════════════════════════════════════════════

[شريط البحث العلوي - ممتد بعرض كامل]
  ├─ ⚙️ إعدادات (Popover)
  ├─ 🔍 بحث موحد
  └─ 💾 النتائج المحفوظة (Popover)

[السبورة السوداء - جميع النتائج]
  └─ كل نتيجة = زر عريض قابل للضغط
      └─ الضغط → Dialog [معاينة + سياق + أزرار كلمات]
          └─ ضغط كلمة → Dialog Nested [نتائج اللفظ]


🎯 خطوات الاستخدام:
════════════════════════════════════════════════════════════════════════════════

1. اكتب في البحث (كلمة أو آية)
2. النتائج تظهر فوراً كأزرار
3. اضغط على أي زر
4. نافذة عائمة تفتح تعرض:
   - الآية الكاملة
   - السياق الموسع
   - أزرار الكلمات
   - زر الحفظ
5. اضغط على كلمة لبحث متداخل
6. اضغط 💾 لحفظ النتيجة


⚙️ الإعدادات:
════════════════════════════════════════════════════════════════════════════════

الافتراضي: 2 قبل + 2 بعد
يمكن التغيير: 1-20 آية
يؤثر على جميع النتائج فوراً


💾 الحفظ:
════════════════════════════════════════════════════════════════════════════════

الملف: data/مجلد_النتائج.txt
يحتوي على:
  • الآية والسياق
  • الاستعلام الأصلي
  • طابع زمني لكل إدخال
يمكن المسح من 💾 النتائج
